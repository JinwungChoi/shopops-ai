# 쇼핑몰 고객센터 시연

Style Shop은 합성 정책을 사용하는 의류몰 고객센터 데모입니다.

- [Style Shop 실제 모델 채팅](http://127.0.0.1:3031/chat/202dbac4609c4aaa9a7cd4ea0aa604a5)
- [정책 원문 23개](showcase-policies.json)

질문을 보내고 답변 아래 정책 출처를 펼쳐 보세요. 반품 기한은 수령 후 7일, 기본 무료배송 기준은 5만 원, 단순 변심 왕복 반품비는 6,000원입니다.

## 채팅 상품 추천

[실제 모델 브라우저 시연 영상](style-shop-walkthrough.webm)

1. **신상 재킷 보여줘**로 블랙 트윌 재킷과 스톤 칼라 재킷의 가격·옵션을 확인합니다.
2. **M 사이즈만**으로 재고가 있는 블랙 트윌 재킷만 봅니다.
3. **받고 나서 반품은 며칠까지 돼?**로 정책 답변과 출처를 확인합니다.
4. **6만 원 미만 신상 재킷 보여줘**로 결과 없음 안내를 확인합니다.

합성 카탈로그에는 재킷 두 종류, 아이보리 옥스퍼드 셔츠, 차콜 플리츠 팬츠가 있습니다. 가격·옵션·재고는 서버의 합성 상품 데이터에서 조회하며, 상품 조건은 같은 상담 세션에서 이어집니다. 정책 질문은 기존 RAG가 처리합니다.

추가 상품 이미지는 내장 ImageGen으로 생성했습니다. 프롬프트는 정사각형 제품 사진, 전면 인비저블 마네킹, 연회색 배경, 부드러운 조명, 무지·무로고를 공통으로 사용했습니다.

- [차콜 플리츠 팬츠](../public/demo-products/charcoal-pleated-trousers.png) · 싱글 플리츠, 스트레이트 레그, 전신 길이

## 주문 조회와 반품 접수 시연

Style Shop 실제 모델 채팅 상단의 **[비로그인] [고객 A] [고객 B]** 버튼으로 데모 고객을 바로 전환합니다. 전환하면 새 대화가 열립니다.

| 데모 고객 | 이메일 | 모의 주문 |
|---|---|---|
| A | style-customer-a@example.com | 기본 12건. STY-1001 블랙 트윌 재킷 배송 중, 반품 기한이 다른 린넨 셔츠 주문 2건 |
| B | style-customer-b@example.com | 기본 8건. STY-2001 아이보리 옥스퍼드 셔츠 배송 완료, 출고 준비 및 배송 중 주문 |

두 계정의 데모용 비밀번호는 `StyleShop-Demo-2026!`입니다. 로컬 시드가 만드는 합성 고객입니다.

1. **신상 재킷 보여줘** → 모델이 상품 검색을 선택합니다.
2. **M 사이즈만** → 같은 세션의 상품 조건을 좁힙니다.
3. **내 재킷 배송 어디까지 왔어?** → 택배 추적을 선택하고 STY-1001의 마지막 스캔(군포 물류센터)과 이동 내역을 보여줍니다.
4. **내 주문 내역 조회좀** → 최근 주문 최대 20건을 날짜·금액·배송 상태와 함께 보여줍니다. 기본 시드에서 고객 A에게는 12건이 표시됩니다.
5. **STY-2001 배송 상태 알려줘** → 고객 A로는 이 주문을 찾을 수 없습니다.
6. **반품은 며칠까지 돼요?** → 정책 검색을 선택하고 7일 정책과 출처를 표시합니다.

**지금 반품가능한게 어떤거야?**라고 물으면 로그인한 고객의 주문 중 지금 반품을 신청할 수 있는 상품만 표시합니다. **이 주문은 왜 반품할 수 없어?**처럼 판정이나 사유를 물으면 배송 완료 전, 기한 초과, 접수 완료 등의 결과를 확인할 수 있습니다.

실제 모델 시연에서는 **내 주문 내역 조회좀** 다음에 **그중 지금 돌려보낼 수 있는 옷이 뭐뭐야? 보내려면 돈이 얼마 드는지도 알려줘.**라고 물어보세요. 앞에서 보여준 주문의 반품 상태와 비용 정책 출처를 한 답변에서 확인할 수 있습니다.

답변을 기다리는 동안 화면에는 실제 도구 선택과 조회 단계가 표시됩니다. 택배 위치는 합성 스캔 기록의 마지막 위치입니다.

7. **STY-1002 반품해줘. 반품비도 알려줘** → 정책 출처와 반품 사유 선택을 확인합니다.
8. **단순 변심**을 선택하고 상품 상태를 체크한 뒤 **반품 접수**를 누르면 모의 접수번호가 나옵니다. 브라우저를 새로고침해도 같은 탭의 유효한 세션에서 접수를 이어갈 수 있습니다.
9. **STY-1002 배송 완료라는데 못 받았어** → 상담 문의를 제안합니다. **상담 문의 접수**를 누른 뒤 해당 쇼핑몰의 관리자 화면에서 **상담 문의**를 열면 마지막 배송 기록과 상담 내용을 확인할 수 있습니다.

반품은 마지막 배달 완료 기록이 7일 이내인 주문에 대해 한 번 접수할 수 있습니다. 새로 시연할 때는 `pwsh -NoProfile -File scripts/seed-mock-orders.ps1 -FreshReturn`을 실행해 고객 B에 어제 수령한 합성 주문을 추가하고, 출력된 주문번호를 사용하세요. 접수는 모의 주문 시스템에 저장됩니다.

로그인·로그아웃하면 브라우저에서는 새 대화가 열립니다. 로그인 상태에서 만든 상담의 주문 내역은 해당 고객의 인증 쿠키와 상담 토큰으로 함께 보호합니다.

```powershell
supabase migration up --local
pwsh -NoProfile -File scripts/seed-mock-orders.ps1
$env:SHOP_OPS_TEST_AGENT = '1'
pwsh -NoProfile -File scripts/test-local-supabase.ps1 -LiveModel
```

마지막 명령 전에 기존 3031 서버를 종료하거나, 같은 실제 모델 데모 서버를 검사할 때 `$env:SHOP_OPS_REUSE_TEST_SERVER = '1'`을 설정합니다.
