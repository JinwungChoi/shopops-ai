# Claude Code 시작 프롬프트

저장소 루트에서 Claude Code를 열고 아래 내용을 붙여넣는다. 마지막 줄에 원하는 작업을 지정할 수 있다.

```text
이 저장소의 ShopOps AI 작업을 이어받아줘. 먼저 루트의 CLAUDE.md와 AGENTS.md, docs/HANDOFF.md를 읽고, 필요한 설계 문서와 현재 코드를 대조해줘. 기존 파일과 로컬 데이터를 그대로 이어서 사용해.

현재 포트폴리오의 공개 시연은 Style Shop 한 곳의 합성 쇼핑몰 CS 에이전트야. RAG의 정책 근거, 모델의 여러 단계 도구 선택, 주문·배송 조회, 고객 확인을 거친 모의 반품 접수와 상담 이관이 핵심이야. 주문과 반품 판정은 서버 데이터에서 확인하고, 실제 접수는 인증된 고객의 명시적 확인을 거쳐야 해.

예를 들어 “내 주문 내역 보여줘” 다음에 “그중 지금 돌려보낼 수 있는 거랑 반품비 알려줘”라고 물으면 앞서 표시한 주문의 범위에서 가능한 주문만 카드로 보여주고 비용 출처를 붙여야 해. “이 주문은 왜 빠졌어?”는 해당 주문의 판정 사유를 따로 반환해야 해. 목록 건수와 카드의 개수는 같은 결과로 맞춰줘.

실패 사례를 받으면 표현별 분기를 추가하기 전에 최근 대화 상태, 모델이 선택한 도구와 인자, 서버 응답, 실제 UI를 비교해서 원인을 확인해줘. 모델이 의도와 도구를 선택하게 하고, 권한·업무 규칙·최종 상태는 서버와 DB가 판정하도록 유지해줘. 화면을 바꾸면 기존 흑백 미니멀 UI에 맞추고 브라우저로 검증해줘.

작업 대상의 수용 기준과 관련 테스트를 먼저 확인하고 변경 뒤 실제 검증 결과를 알려줘. 실제 모델 키나 Supabase 비밀 키는 출력하지 마. 현재 작업과 관련 없는 배포나 Phase 3는 별도 작업으로 다뤄줘.

이번 작업: 우선 인수인계 문서와 코드가 일치하는지 확인하고, 실행 가능한 기본 검증을 돌려줘. 검증 결과와 바로 시작할 수 있는 다음 작업 하나를 알려줘.
```
